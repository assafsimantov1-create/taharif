התעריף — חבילת המוצר
====================

מה יש כאן
---------

site/                 ← זה מה שעולה לדומיין taharif.website
   index.html            האתר כולו: עיצוב, מחשבונים, נתונים וקוד. קובץ אחד.
   og.png                תמונת השיתוף שמופיעה כשמדביקים את הקישור
                         בוואטסאפ, בפייסבוק או במודעה.

buyer-file/           ← זה מה ששולחים לקונה אחרי התשלום
   taarif-access.pdf     אישור רכישה + קוד הגישה + הסבר איך נכנסים.


אזהרה אחת חשובה
---------------

אל תעלה את הקובץ מ-buyer-file לאתר.
הוא מכיל את קוד הגישה. אם הוא יעלה לשרת, כל אחד יוכל להגיע אליו
בכתובת ישירה ולפתוח את הכלים בחינם.
הקובץ הזה נשלח רק במייל/בהודעת המסירה של Gumroad.


איך מעלים לדומיין
-----------------

חשוב: שני הקבצים בתיקיית site חייבים להיות באותה רמה, בשורש האתר.
index.html חייב להישאר בשם הזה בדיוק - זה מה שנטען כשמישהו מקליד
את הכתובת.

אם אתה משתמש ב-Netlify או ב-Cloudflare Pages:
   גרור את התיקייה site כולה לחלון ההעלאה. זה כל התהליך.

אם יש לך אחסון עם FTP או מנהל קבצים (cPanel וכדומה):
   העלה את index.html ואת og.png לתיקיית public_html.

אחרי ההעלאה, בדוק:
   1. הכתובת taharif.website נפתחת ומציגה את האתר.
   2. הדבק את הכתובת בוואטסאפ לעצמך - צריכה להופיע תמונת השיתוף.
   3. גלוש בחלון גלישה בסתר ולחץ "לרכישת גישה" - הצ'קאאוט צריך להיפתח.
   4. הזן את קוד הגישה - שבעת הכלים צריכים להיפתח מתחת.


שתי שורות שאפשר לשנות בעתיד
---------------------------

בתוך index.html, חפש את המילה PAYMENT_URL. שם יושבות שתי שורות:

   var PAYMENT_URL = "https://gumroad.com/checkout?product=ajtwic&quantity=1";
   var ACCESS_CODE = "TAHARIF-2026";

הראשונה היא קישור התשלום. השנייה היא קוד הגישה.
אם תשנה את הקוד - זכור לעדכן גם את קובץ ה-PDF שנשלח לקונים,
אחרת הם יקבלו קוד שלא עובד.

הקוד לא רגיש לאותיות גדולות או קטנות: Taharif-2026 ו-TAHARIF-2026
שניהם יעבדו.


מה קורה אצל הגולש
-----------------

כל החישובים רצים בדפדפן של המשתמש. שום נתון לא נשלח לשרת ואין
בסיס נתונים - ולכן אין מה לתחזק ואין עלות הפעלה חודשית.
הדפדפן זוכר שהקוד הוזן, כך שקונה חוזר לא צריך להקליד אותו שוב.
